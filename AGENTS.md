# Estienne brand assets

Use assets/estienne-monogram.svg as the canonical Estienne logo in all future work on this project. The user selected the interlaced monogram with the central four-point star and the diamond terminal. This SVG contains the original outlined artwork extracted from the supplied Illustrator master.

Do not substitute a plain letter E, a font glyph, an approximate redraw, or an AI-generated version of the mark. Preserve the original paths, aspect ratio and clear space. Material treatments such as blind embossing, silver foil and champagne foil may vary; the silhouette must remain unchanged. Use the same SVG for the header, card, die, envelope seal and subsequent renderings.

The original Illustrator sheet includes personal contact details. Only the isolated logo paths belong in the public website. Keep the source sheet and full-sheet previews out of the repository.

The paper texture assets/cotton-paper.webp was generated with the built-in image generation tool. It intentionally contains no typography or logo; brand artwork stays separate and precise.

## Visual and motion direction

The user rejected the previous stiff station-by-station card animation and supplied an architectural scrolling-film reference. Preserve a continuous camera journey with close-ups, pull-backs, and an orbit, rather than independent eased poses or moving flat tool illustrations. Default to warm ivory cotton. Green is not a required brand or card color; the user explicitly said the card need not be green. The current trial uses warm ivory, stone and an oxblood edge.

The current Terrain trial uses a Blender Cycles frame sequence driven directly by scroll or playback. This supersedes the prior Three.js implementation after the user requested another animation workflow. Preserve the continuous camera journey and exact monogram; do not replace the film with a single static mockup. The 24 fps 960 × 540 sequence is a camera study, not a final master. Keep decoded image memory bounded, support scrubbing in both directions, respect reduced-motion preferences and pause when hidden. Reference videos and original personal stationery sheets must stay out of the public repository.
